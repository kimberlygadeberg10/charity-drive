# Your Next Chapter

This project is a personal and community-focused website called **Your Next Chapter**.  
I created this site as part of my learning journey in web development and to practice building a full webpage using HTML and CSS.

The goal of the website is to share information about healing-focused events, community support, and special gatherings, while also learning how to structure, style, and organize a real website project.

---

## What This Project Is About

Your Next Chapter is meant to represent hope, healing, and moving forward.  
The website includes pages that explain the mission, show upcoming events, highlight team members, and allow users to get in contact or learn about special events like the Founders Dinner and Gala.

This project helped me understand how different parts of a website work together.

---

## What I Learned

While building this project, I learned how to:

- Create multiple pages using HTML
- Link pages together with navigation
- Style pages using CSS
- Use Flexbox and Grid for layouts
- Add images and fix image path issues
- Create buttons and forms
- Push my code to GitHub using the terminal
- Organize files and folders for a real project

---

## Features

- Home page with a hero section and mission statement  
- About page with team member cards and images  
- Events page with upcoming events and special events  
- Event gallery with images  
- Contact form for users to reach out  
- Buttons for buying tickets or reserving seats  
- Responsive layout for different screen sizes
